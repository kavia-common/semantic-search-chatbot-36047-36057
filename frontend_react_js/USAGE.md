# RAG Chatbot Frontend (React)

This is the Ocean Professional themed React frontend for the Semantic Search RAG Chatbot.

## Configure
Create a .env file in this directory (or set environment variables) with the backend API base:
- REACT_APP_BACKEND_URL=https://your-backend/api

If not set, the app defaults to "/api" on the same origin.

## Run
- npm install
- npm start

## Features
- Sidebar navigation with conversations and document manager
- Chat interface with streaming token support
- Chat history CRUD (create, rename, delete, select)
- Document upload, list, delete, and retrieval preview
- Ocean Professional theme (blue and amber accents, modern cards, rounded corners)
